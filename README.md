# Niumer

**v1.1.8** · by **200Kg** · 联系我：**zwz888123@gmail.com**

Windows 任务栏上的一个小工具条，**固定 186 × 32**，贴在右下角不挡事。能干五件事：算你每秒赚多少钱、上班偷偷背单词、把小说塞进一行字里看、摸鱼敲木鱼攒功德、顺便提醒你喝水起身。

---

## 为什么做这个

上班盯着的那些大屏小屏都不如任务栏实在 —— 它永远在最前面，永远没人管你在上面放什么。所以把想看的都塞进这 186 × 32 里：

- 想知道今天摸到哪一步了，抬眼就能看见
- 想背单词又不想开 App，一行英文远看就是一行普通文字
- 想看小说又怕被发现，鼠标一移开它立刻变成天气
- 想攒点功德又不想下个 App，空格敲一敲就是一天

不注册、不登录、不上传，除了取天气不联网。设置全存在本机注册表里。

---

## 四个页面 + 天气伪装

左键按住小条水平拖一下就能换页，右下角是个**分成四段的圆环**，当前页那段用绿色标出；以后加页只是多分一段，不会挤到内容。天气伪装是小说页的悬停状态，不单独占一页。

### 1. 实时工资条

按你填的月薪折算，精确到分。折算口径是**月薪 ÷ 每月工作日 ÷ 每天工时**，其中每月工作日（默认 22 天）和上班 / 下班时间（默认 09:00–18:00）都在设置里改。

显示的是**今天从上班到现在**已经过去的那些时间换来的钱：中午才开机，上午的部分照样算进去；过了下班时间停在整天金额；早于上班时间是 0。也可以只显示每秒速率，不显示累计金额。

### 2. 单词卡

一行英文 + 音标 + 释义。点一下小条让它获得焦点，按**空格**进入默写：

每个字母一条下划线，自己拼一遍。拼错会标红，拼对了进下一个词。内置三套词库：**四级 2602 词、六级 2344 词、考研 3727 词**，按字母序排列，切换词库时进度分开记。

### 3. 摸鱼阅读

导入 txt 自动分章，正文直接在小条里滚。**鼠标停在条上才走，移开立刻停**，滚轮可以手动翻。字太小看不清可以进设置调。

自带一本原创短篇《十七楼的天台》，装好就能直接读，不用先去找 txt。

### 4. 天气伪装

小说页的状态下，**鼠标一离开小条，正文就换成城市 / 天气 / 气温**。同事凑过来只会以为你装了个天气小挂件，鼠标移回去小说立刻回来。

天气 30 分钟更新一次，数据超过 3 小时会老实标出「几点更新」，不装懂。

### 5. 电子木鱼

第四页左边是只**透明底单线简笔木鱼**，右边是累计功德数。轻点小条拿到焦点后按**空格**敲一下 +1，按住空格自动连击；鼠标按住小条超过 250ms 也会连击，每 160ms 一下（轻点不敲，免得切页误触）。

敲击反馈很轻：木鱼左右微震 150ms、计数小幅上抬再落回；旁边随机飘出一句「功德+1 / 财富+1 / 好运+1 / 开心+1 / 摸鱼+1」，最多同时 4 条，向上缓飘、渐变淡出，350～600ms 后消失。配色低饱和，浅色主题下是柔和深灰与淡彩，适合办公场景。

功德只存在本机，跨天、重启都不清零，设置里可以手动清零。不联网、不上传。

> 页码指示是固定大小的圆环，按页面数等分。以后加到第五页、第六页也只是多分几段，不会往左挤内容。

## 设置中心

工资 / 单词 / 阅读 / 提醒 / 木鱼 / 外观 各占一页，左侧是六个手绘单线简笔图标（硬币 / 卡片 / 铃铛 / 书 / 木鱼 / 日月），选中项线条转白、配实底高亮；改完点右下角一次保存。配色自动跟随 Windows 深浅色。

带一份完整的使用帮助（右键 → 使用帮助），11 个章节逐条讲清每个功能怎么用。

## 快速开始

### 直接用

到 [Releases](https://github.com/zwz888mm/niumer/releases) 下载，两种拿法看你好哪口：

- **安装包**（推荐）：`Niumer-Setup-1.1.8.exe`，双击下一步到底。装到当前用户目录（`%LOCALAPPDATA%\Programs\Niumer`，不需要管理员），带开始菜单项、桌面快捷方式（可取消）、可选开机自启，卸载在「设置 → 应用」里。
- **绿色版**：`Niumer.exe` 单文件，约 28 MB，双击即用，不写安装信息。

两个都不用装 Python，也不用装任何运行库。

> **启动速度**：安装包用的是「目录版」——安装时就把运行文件释放到程序目录，启动直接用；绿色版是单文件，每次启动要把 28 MB 解压到临时目录，明显慢一些。想要开机秒开，用安装包。两者功能完全一样。

> 首次运行 Windows SmartScreen 可能提示「已保护你的电脑」，点「更多信息」→「仍要运行」即可 —— 程序没做代码签名。

### 从源码跑

```bash
pip install -r requirements.txt
python main.py
```

需要 Python 3.10+ 和 PyQt6。

## 操作方式

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 切换四个页面 |
| 左键轻点 | 让窗口获得焦点（能接键盘了）；小说页暂停/继续；木鱼页不敲 |
| 鼠标长按 | 木鱼页按住 250ms 后连击，每 160ms 一下 |
| 右键 | 弹出菜单（设置 / 帮助 / 隐藏 / 退出） |
| 空格 | 单词页进入默写；木鱼页敲一下（按住连击） |
| 滚轮 | 在小说页手动翻正文 |
| 鼠标悬停 | 小说开始滚；移开变天气 |
| `Ctrl + Q` | 隐藏 / 显示窗口 |

## 自己打包

```bash
python build.py
```

产物在 `dist/<版本号>/`：
- `Niumer.exe` —— 单文件绿色版（`Niumer.spec`），约 28 MB
- `runtime/Niumer/` —— onedir 目录版（`Niumer-dir.spec`），安装包用，启动免解压
- `Niumer-Setup-<版本号>.exe` —— 安装包（装了 Inno Setup 才有）

两个 spec 都剔掉了用不到的 Qt 组件（软件 OpenGL、翻译文件），**但 ssl / libssl / libcrypto 必须留着** —— 取天气走 HTTPS，删了天气就废。

装了 [Inno Setup 6](https://jrsoftware.org/isinfo.php) 的话，`build.py` 会自动把目录版编成安装包（约 22 MB）；没装就只出 exe 和目录版。重跑时已存在的产物会跳过，不会被覆盖。

## 界面自检

改完界面别肉眼盯，跑一下：

```bash
python ui_selftest.py
```

30 项检查，包括：

- 各页文字 / 次要文字 / 弱提示的对比度（WCAG）
- 四页在正常和极端数据下，内容都不超出右侧边界，页码环不与文字重叠
- 帮助页节数与配图齐全
- 五个设置面板横不溢出、竖不用滚动

越界检测的做法是**同一页渲染两遍**（一遍正常、一遍关掉页码环）做像素差，不靠颜色常量猜 —— 抗锯齿会把绿色弧染成别的色，精确匹配全部漏掉。

再跑一遍反向对照，确认检测器不是摆设：

```bash
python ui_selftest_negative.py
```

它故意把内容顶到边、把文字压暗，检测器必须报错才算通过。

## 说明

- **只能在 Windows 上跑**，代码里用了 `ctypes` / `winreg` 直接调系统 API，不支持 Win7/8 和 32 位系统。
- 内置词表来自开源项目 [qwerty-learner](https://github.com/Kaiyiwing/qwerty-learner)（MIT），已过滤短语、统一音标并排序，随 exe 一起打包，离线可用。
- 小条是贴在任务栏上的悬浮窗。Windows 的任务栏被点一下会把自己顶到最前面，把小条整块盖住（看着像窗口消失了）。代码里加了置顶守护，每 200 ms 检查一次，被任务栏盖住就自动顶回来。
- `Ctrl + Q` 是全球热键，被别的软件占用时会静默失效。
- 天气数据来自公开接口，取不到就显示缓存，不会编。
