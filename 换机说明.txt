窝囊费 —— 换机调试说明
================================

一、直接运行（不用装环境）
--------------------------------
dist/窝囊费.exe 是现成的单文件程序，Win10(1809+)/Win11 x64 双击即可。
settings.json、词库、月薪等配置存在系统用户目录（QSettings），
换机后是全新的，首次运行默认月薪 3000。


二、改代码 / 重新打包
--------------------------------
1. 装 Python 3.12 或 3.13（64 位），勾选 Add to PATH
2. 进到本目录，装依赖：
      python -m pip install -r requirements.txt
   如果 pip 被代理卡住，用：
      python -m pip install -r requirements.txt --index-url https://pypi.org/simple
   或临时清掉代理环境变量后再装
3. VS Code 打开本文件夹，右下角选 Python 解释器，F5 运行 main.py
4. 重新打包：双击 build.bat（或命令行 python build.py）
   产物在 dist/窝囊费.exe，约 25MB 单文件
   注意：打包前先把正在跑的窝囊费关掉（托盘右键退出），
   否则 exe 被占用，PyInstaller 删不掉旧文件会报错
5. 改完界面代码建议跑一遍自检（见下面「文件说明」里的两个脚本）


三、文件说明
--------------------------------
main.py              全部源码（工资条 + 单词卡 + 健康提醒 + 摸鱼阅读 + 设置中心）
ui_selftest.py       界面自检：小条排版越界、对比度、帮助配图、四个设置面板尺寸
ui_selftest_negative.py  反向对照：故意把版面弄坏，验证自检真的会报错
build.py             打包脚本，调用下面的精简配置
窝囊费-slim2.spec    PyInstaller 配置，已剔除多余 Qt 组件
build.bat            双击打包用
logo.ico             程序图标
我的词库.txt         词库示例，可照格式改成自己的词
考研核心词.txt       考研词表（261 词，仅供查阅；已内嵌进程序）
.vscode/             编辑器配置（解释器需换机后重选）
requirements.txt     依赖清单（只有 PyQt6 和 pyinstaller）
preview-*.png        界面预览图（小条深/浅色、设置中心、帮助窗口、天气页）
dist/窝囊费.exe      现成程序，可直接拷走用

自检怎么跑（在 desktop-tool 目录下，命令行）：
    python ui_selftest.py
    python ui_selftest_negative.py
第一条列 28 项检查，全 PASS 退出码 0；第二条用来证明第一条不是“永远通过”，
三个对照项都会打印「探测器有效」。


四、单词学习
--------------------------------
- 三套词库：高频核心词(46)、考研核心词(261)、自定义导入
- 设置中心 → 单词卡 → 选词库，三套进度各自独立保存
- 每个词记录状态：未学 / 待巩固（答错过）/ 已掌握
- 单词条右上角显示「当前/总数」，鼠标悬停看详细进度
- 重启程序自动从上次位置继续背；「跳到未掌握」可只复习错的词
- 「重置进度」只清当前词库记录，不动其他词库

五、摸鱼阅读（看小说）
--------------------------------
- 设置中心 → 摸鱼阅读 → 「导入 txt」，支持多选，自动识别
  UTF-8 / GBK / GB18030 编码（中文 txt 常见为 GBK），单本上限 8MB
- 正文就排在任务栏那条 186x32 的小框里，一次显示两行，不弹任何窗口
- 鼠标停在小条上才往下滚，鼠标一移开立刻停（这就是防老板模式）
- 小条上滚轮可手动往上/往下挪；轻点小说页暂停/继续
- 挂在小条底部有一条细进度条；百分比和状态在鼠标悬停提示里
- 字号 10~20px、速度 4~80px/秒，按自己眼神在设置里调
- 阅读位置按「读到第几个字」记，改字号、重启、换书再换回来都能接上

六、小说页的天气伪装
--------------------------------
- 鼠标不在小条上时，第三页显示当地天气：城市 + 天气现象 + 气温，
  第二行是今日最高/最低与湿度；鼠标一移回来立刻恢复小说并接着滚
- 数据源：open-meteo 为主，不通时自动换 wttr.in；定位按公网 IP
- 想固定城市：设置中心 → 摸鱼阅读 → 「鼠标移开时（伪装成天气）」里填城市名，
  留空＝自动定位；旁边「立即刷新」可手动取一次
- 每 30 分钟自动更新；断网时继续用上一次的数据，超过 3 小时第二行改标“几点更新”
- 不想要这个效果：把那一项的勾去掉，鼠标移开会停在原处
- 注意：需要能上外网。公司网络若拦了外网或代理不通，会显示“天气暂无数据”，
  这属于网络限制，不是程序坏了

七、使用帮助
--------------------------------
- 右键小条 → “使用帮助...”，或设置中心右下角“使用帮助”
- 左边 10 个章节，按顺序翻一遍基本就没疑问了：
    30 秒上手 / 工资条 / 单词卡 / 摸鱼阅读 / 天气伪装 /
    健康提醒 / 设置中心 / 快捷键与手势 / 数据与迁移 / 常见问题
- 每节都配了界面实拍图。这些图不是事先截好放进去的，而是打开
  帮助时按当前系统深浅色现场画出来的，所以和你屏幕上看到的一致；
  单文件 exe 里也带着，不依赖外部图片。
- 小条上不再弹鼠标悬停提示（原来那大块文字挡视线，已取消），
  信息全在帮助页里；托盘图标仍保留一行简短提示。

八、界面与配色
--------------------------------
- 设置中心和帮助统一成一套中性配色：浅灰底 + 白色卡片 + 一条细边框，
  全局只有一种蓝色作为强调色（原来那种蓝紫渐变、到处发光的效果已经去掉）
- 深浅色跟随 Windows 的「应用模式」自动切换，不用手动选
- 小条本身仍是 186x32，三页都在这一个框里切换，不会撑大也不会另开窗
- 长内容会自动缩字号或省略（金额极大、单词极长都试过），
  右侧页码指示始终留出位置，不会和文字压在一起

九、几个要注意的点
--------------------------------
- 健康提醒的间隔单位是「分钟」，1~720 分钟；老版本按小时存的配置
  会自动换算成分钟，不用手动改。
- 程序启动时会自动注册全局热键 Ctrl+Q 隐藏/显示窗口；
  若被别的软件占用，功能会静默失效，不会有提示。
- 健康提醒走 Windows 系统通知中心，若被「专注助手/免打扰」
  拦截，需去系统通知设置里放行窝囊费。
- 小条是贴在任务栏上的悬浮窗。Windows 的任务栏只要被点一下，就会把
  自己顶到最前面，把小条整块盖住（看着就像窗口消失了）。代码里加了
  「置顶守护」，每 200ms 检查一次，被任务栏盖住就自动顶回来，不用管。
  万一还遇到，Ctrl+Q 隐藏再按一次即可恢复。
- 程序做了单实例保护：重复双击 exe 不会开出第二条小条，
  只会把已有的那条叫到前面来。
- 代码里用了 ctypes/winreg 调 Windows API，只能在 Windows 跑，
  不支持 Win7/8、32 位系统。
- 改完代码重新打包即可，本机不需要装 Qt 开发环境。
